# 版本记录

版本号以 `deploy/layers/qm-cn/VERSION` 为准。工作台品牌名旁显示当前版本，“设置 → 版本”中可以查看这一版和以往各版的更新内容。

每次发布都提升版本号并在这里写明更新内容，热修复提升最后一位（如 0.4.1）。没有更新内容的版本无法构建。

## 0.4.6

换上默契的新标志，不再显示 Slack，带入项目多了一个入口，表情补全更好用，另有技能包的两处修正。

### 改进

- **不再显示 Slack**：我们不使用 Slack，网页和后台不再显示 Slack 相关的设置、引导、标签页和选项。
- **带入项目**：个人会话顶部右侧的按钮行最前面多了一个文件夹图标“带入项目…”，点击即可打开带入项目的对话框，不必再到侧栏菜单里找。侧栏菜单中的入口保留。
- **表情补全**：在空格后或输入框开头只输入一个冒号，就会列出常用表情；中文输入法下的全角冒号“：”也可以。再输入一个字母即可筛选，不必再输入两个字母。像“注意：”或“12:30”这样的冒号不会弹出表情。
- **新标志**：浏览器标签页图标、侧栏和后台都换成默契的符契标志：一个方块沿阶梯状的缝分成两半，两半正好合在一起。深色模式下显示浅色版本，侧栏展开时两半沿同一条缝合拢。
- **技能包**：后台“移除技能包”的确认提示改为“删除其导入的技能”，与实际行为一致。
- **技能包同步**：开启了“自动同步”、但固定在某次提交上的技能包，不再在每次同步时重复导入。

## 0.4.5

个人会话可以带入项目；文件可以直接预览，会话分叉更快，打开时可以直接开始新聊天，另有多项稳定性和安全更新。

### 新功能

- **把个人会话带入项目**：在侧栏中打开自己的个人会话的菜单，选择“带入项目…”，再选一个你所在的项目，就会在该项目中生成这次会话的副本。
  - 带过去的内容：你和助手的对话、工具输出，以及这次会话产生的文件。项目现有和以后加入的成员都能看到。
  - 不带过去的内容：你的个人记忆、助手的思考过程、助手查阅你其他会话的结果，以及你已删除的消息。
  - 原会话保持私密、不受影响，它的菜单中会出现“打开 … 中的副本”。
- **文件预览**：在聊天附件和“文件”页中点开 Markdown、表格（CSV）和文本文件即可预览，可以复制内容或下载。表格预览最多显示 1,000 行、100 列，超过 2 MB 的文件以纯文本显示。
- **打开时的会话**：“设置”中的“打开时”可以选择“上次的会话”或“新聊天”。
- **表情补全**：在输入框中输入冒号加名称（如 `:smile`）即可选择表情。
- **花费统计自定义时段**：后台“花费”页选择“自定义”，可以按日期范围查看（UTC，最长 366 天）。

### 改进

- **会话分叉**：分叉更快；在分叉出的会话中也可以从某条消息继续分叉；分叉进行中会显示“正在分叉”。
- **自定义模型**：后台模型供应商的模型行增加第五列“推理（true/false）”，原有的附加信息 JSON 移到第六列，旧格式仍然可用。不填第六列会保留原有的附加信息，填 `{}` 可清空。
- **子助手**：子助手完成后会唤醒等待它的会话；子助手的记录中显示它被委派的任务。
- **目标**：长时间没有进展的目标会先调整做法，仍无进展时暂停。暂停时助手会向你提问，你在会话中回复或让它继续，目标就会恢复。
- **更省的会话**：每轮发送给模型的上下文更精简。
- **稳定性**：后台数据库故障不再导致服务中断；发布新版本时被打断的工具调用会在安全时自动重试。
- **安全更新**：升级了多项依赖，修复已公开的安全问题。
- **使用与成果**：页面上的时间改标为北京时间；导出的两个表格文件名改为 `adoption.csv` 和 `request-scenarios.csv`。
- **示例电话**：电话输入框的示例号码改为 `0123-0123 4567`。
- **分屏**：最多可以同时打开 16 个会话。
- **额度提示**：模型服务账户的额度用完时，会明确提示“模型额度已用完”，并提示联系管理员调整额度或充值。

### 修复

- 退出登录后不会再被自动登录回去。
- 后台“审计”页按资源筛选时，`%` 和 `_` 按字面匹配。

### 升级说明

- 文件共享改为按文件记录关联。个别直接按路径共享、没有对应文件记录的文件，升级后需要重新共享。如果同事反映打不开你以前共享的文件，重新共享一次即可。
- 升级前已经发布并共享的应用不受影响，原来能打开的人仍然能打开。此后，在个人会话中新发布的应用默认只有你自己能打开，需要让助手另行共享；重新发布、改名或回滚只更新内容，不会改变谁能打开。
- 少数自动保存的工具登录凭据会被清除，相关同事下次使用该工具时需要重新登录一次。
- 很长的会话带入项目后，副本中的第一次回复会比平时慢一些。
- 项目中的其他成员看到副本上的“分叉自 …”时，点击会提示“你已无权访问原会话”。这是正常的，因为原会话仍然只属于它的主人。

## 0.4.4

会话标题栏开头标明会话所在的范围，一眼就能分清项目会话和个人会话。

### 改进

- **会话所在范围**：每个会话的标题栏开头都有一个标签。项目、频道或群组会话显示它的图标和名称，带主题色底色；个人会话显示“个人”。分屏的每个窗格和单栏视图都会显示，窄屏下标签缩短但不会隐藏。
- **示例电话**：后台和“设置 → 联系方式”中，电话输入框的示例号码改为虚构的号码。

## 0.4.3

可以在设置中自己填写电话、从五套配色中任选；通讯录中未分配部门的同事只对管理员显示。

### 新功能

- **自己填写电话**：在“设置 → 联系方式”中可以填写、修改或清除自己的电话，保存后同事即可在通讯录中看到（还没有分配部门的同事，只有管理员能看到）。邮箱就是登录账号，不能在这里修改。每次保存都记入审计日志，日志中不含号码。管理员模拟登录他人时不能修改。
- **配色**：“设置 → 配色”提供素白、雾蓝、青瓷、象牙、墨五套配色，每套都有浅色和深色版本，与“主题”中的浅色、深色、跟随系统搭配使用。选择即时生效，只保存在当前浏览器，并同步到已打开的其他标签页。与组织当前配色一致的一套标为“组织默认”，选它即恢复跟随组织。正在使用导入的主题文件时，选择配色会替换它，主题随之改为跟随系统。

### 改进

- **通讯录**：还没有分配部门的同事只有管理员能看到，分组标为“未分配部门 · 仅管理员可见”，方便管理员补全部门。

## 0.4.2

通讯录可以查看和复制同事的联系方式，“设置 → 版本”中可以查看以往各版的更新内容。

### 新功能

- **通讯录联系方式**：每位同事显示登录邮箱，后台登记过电话的还显示电话。点击邮箱或电话即可复制，悬停显示完整内容。搜索可以按邮箱或电话查找，电话中的空格和横线不影响匹配。
- **后台登记电话**：后台“用户”中打开某人，在“联系方式”卡片中填写或清除电话，分机可以写作“0123-0123 4567 转 806”。邮箱就是登录账号，不能在这里修改。每次保存都记入审计日志，日志中不含号码。助手无法读取或修改电话。

### 改进

- **版本历史**：“设置 → 版本”中点“本版更新”，除本版内容外，还可以在下方“历史版本”中逐个展开以往各版。

## 0.4.1

回答评价和后台“使用与成果”页的一次小更新。

### 改进

- **回答评价**：评过的回答和交付文件一直显示“有帮助”或“没帮上”标签，不必悬停。点击标签取消评价，也可以改为另一种评价。
- **使用与成果**：“场景分布”和“场景每日趋势”中每个场景使用各自的颜色，柱状图、趋势线和图例中颜色一致，“未分类”为灰色。

### 修复

- **使用与成果**：“每日使用趋势”和“部门使用分布”的标题不再被指标选择框遮住。

## 0.4.0

在 0.3 的基础上，加入一批面向同事的新功能和修复。

### 新功能

- **会话状态**：侧栏和会话列表为每个会话显示运行中、等待你、失败或已完成，刷新后保持。未读圆点只出现在铃铛计为未读的会话上。
- **通知铃铛**：
  - 已读会话留在列表中，变暗显示。
  - 自己发起的任务完成后单独一行。
  - 提到你的消息标为提及，弹窗保留到你打开为止。
  - 支持全部标为已读，也可以只静音任务提醒。
  - 公告作为一行出现，从铃铛打开后横幅消失。
  - 被他人加入项目时收到通知。
- **图片翻页**：会话中点击图片打开预览，用左右方向键或按钮翻页，并显示当前位置。
- **回答评价**：可以给回答和交付文件点赞或点踩，点踩时可以写原因。后台“评价”页按模型和技能汇总。
- **运行进度**：长任务的状态行显示总用时，思考期间持续计时，刷新不清零。
- **项目**：
  - 项目列表按置顶、重要或紧急、最近排序。
  - 侧栏中点箭头展开项目，点名称打开项目，手机上同样可用。
  - 项目所有者可以预览后整部门加入。
  - 文件面板分开交付文件和过程文件，搜索同时覆盖两者。
  - 成员可以自行退出项目。
- **通讯录**：“浏览”中新增通讯录，按部门列出在职同事，可搜索。
- **后台重置密码**：后台“用户”中打开某人，可以把密码恢复为其最初获得的初始密码。恢复后此人在所有设备上退出登录，下次登录须设置新密码。页面不显示也不发送密码。

### 改进

- **侧栏精简**：只保留首页、搜索、浏览和新建会话，其余页面都在“浏览”中，会话列表上移。完成新手引导后，成长卡折叠为一行。
- **品牌**：
  - 工作台和后台的浏览器标签图标使用品牌图标。
  - 组织可以配置亮色和暗色主题。
  - 公告横幅和阅读器显示品牌名。
  - 打开侧栏时组织标识两半合拢。
- **版本**：品牌名旁显示版本号，“设置 → 版本”可以查看本版更新内容。
- **推理强度菜单**：只列出当前模型实际支持的档位。
- **个人 AI 账号**：国内主机无法连接 Claude 和 ChatGPT，“设置”中不再显示“AI 访问权限”，全员使用公司模型。

### 修复

- 回答失败时显示中文提示。
- 后台设置页：基础模型使用自定义供应商时显示为已就绪，并列出已配置的供应商。
- 花名册中出现格式异常的行时，服务继续运行。

## 0.3.x

0.3.0 于 2026-10-11 发布，基于上游最新版本重建。此后的热修复：

- 引导页：基础模型使用自定义供应商时，不再误报尚未配置模型。
- 侧栏重新显示部门文档和项目管理入口。
- 侧栏品牌标识重新按组织品牌显示。
- 在会话中点击“首页”回到首页，不再新增空会话。
- 项目和群聊中，每条消息重新显示发言人姓名。
