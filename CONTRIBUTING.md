# 参与贡献 · Contributing

[中文](#中文) · [English](#english)

## 中文

### 报告问题

直接开 issue，中文或英文都可以。写清楚你做了什么、看到了什么、期望看到什么，以及版本号（设置 → 版本）。如果问题在上游 [qm](https://github.com/yc-software/qm) 中同样存在，也请报告给上游。

### 提建议

开 issue 说明你想要的变化和原因，像跟同事聊天一样随意写就好。请不要让 AI 把它扩写成正式提案。

### Pull request

欢迎提交，但这里不会直接合并 PR：本仓库每个版本发布一次快照。我们认可的改动会在内部实现，随之后的版本发布，提交中会以共同作者（Co-authored-by）署名你；之后我们关闭 PR，并附上包含它的版本链接。

### 我们承诺什么

- 每个 issue 和 PR 都会有人读过、审过，再决定是否去做。
- 不承诺回复时间，也不承诺一定实现。

### 安全问题

请不要开公开 issue。见 [`SECURITY.md`](./SECURITY.md)，通过本仓库的 **Security → Report a vulnerability** 私下报告。

## English

### Bugs

Open an issue, in Chinese or English. Say what you did, what you saw, what you expected, and the version (Settings → Version). If the problem also happens in upstream [qm](https://github.com/yc-software/qm), please report it there too.

### Ideas

Open an issue describing the change you want and why, informally, the way you would tell a colleague. Please do not have AI expand it into a formal proposal.

### Pull requests

Welcome, but pull requests are not merged here: this repository receives one snapshot per release. Changes we accept are rebuilt internally and ship in a later release, with you credited as co-author (`Co-authored-by`). We then close the pull request with a link to that release.

### What we promise

- Every issue and pull request is read and reviewed before we decide whether to build it.
- No promised response time, and no promise that a request will be built.

### Security

Do not open a public issue. See [`SECURITY.md`](./SECURITY.md) and report privately through this repository's **Security → Report a vulnerability** flow.
